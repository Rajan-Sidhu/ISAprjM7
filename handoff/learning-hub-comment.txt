Project title and description: Motion Fighter is an AI motion planner for a four-servo desktop robot. A person describes a movement in ordinary language, or records about one second on a webcam. The API embeds that input with a locally hosted copy of VideoPrism and matches it to motions for the base, shoulder, elbow, and gripper. The client plays the resulting servo plan. Accounts, saved plans, and API usage are stored in separate database tables. Passwords are stored as bcrypt hashes. Login is our own email and password check.
